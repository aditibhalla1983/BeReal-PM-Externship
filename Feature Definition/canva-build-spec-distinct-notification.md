# Canva Build Spec — Distinct Notification Treatment
### Copy-paste-ready content for building the clickable prototype yourself

---

## Setup

1. Go to [canva.com](https://www.canva.com)
2. Create a new **Presentation (16:9)**
3. Rename it: **BeReal Feature Prototype – Distinct Notification Treatment**
4. Create **5 slides** (one per screen below)

**Style guide (apply to every slide):**
- Background: white or light beige
- Font: Inter, Open Sans, or Poppins
- Colors: neutral + one soft accent (muted yellow or soft blue) — avoid bright red
- No gradients, no heavy shadows — flat and calm
- Rounded buttons, generous white space
- One phone-frame mockup per slide (Elements → search "phone mockup" or "mobile frame")

---

## Slide 1 — Notification (Trigger)

**Magic Design prompt to try:**
> "Minimal lock-screen mobile notification mockup, soft green glow border, clean sans-serif text, light background"

**Header:** Your daily BeReal alert

**Visual:** Phone lock-screen mockup with a notification card — add a soft green border/glow around it (Elements → search "notification bubble" or draw a rounded rectangle with a colored border)

**Microcopy** (use Magic Write to refine if needed):
> "2 min left to capture today's moment"

**Button:** "Tap notification" → **links to Slide 2**

---

## Slide 2 — Camera / Action

**Magic Design prompt to try:**
> "Simple mobile camera app screen mockup, minimal UI, neutral colors"

**Header:** Camera opens as usual

**Visual:** Phone mockup with a plain camera icon or simple dual-camera illustration — keep this intentionally plain, since this screen is meant to show *nothing changed*

**Microcopy:**
> "Nothing about the capture screen changes — same dual camera, same one shot."

**Buttons:**
- "Post" → **links to Slide 3**
- Small text link: "What if the alert fails to load?" → **links to Slide 4**

---

## Slide 3 — Success (Reward)

**Magic Design prompt to try:**
> "Warm success confirmation screen for a mobile app, soft yellow accent, celebratory but minimal"

**Header:** Nice one, Aditi — your BeReal is live! 🔆

**Visual:** A simple checkmark or sunburst icon (Elements → search "sunburst" or "confetti minimal" — keep it small and subtle, not loud)

**Microcopy:**
> "A small, warm confirmation. No streak counter, no score — just a moment noticed."

**Button:** "Done" → **links back to Slide 1** (completes the loop)

---

## Slide 4 — Fallback (Error, silent)

**Magic Design prompt to try:**
> "Plain minimal mobile notification mockup, no special styling, neutral gray"

**Header:** Sound fails to load

**Visual:** The same phone lock-screen mockup as Slide 1, but with a **plain, unstyled** notification — no glow, no color accent, standard system look

**Microcopy:**
> "(no microcopy shown — the failure is invisible to the user, on purpose)"

**Button:** "Continue as normal" → **links to Slide 2**

*Note in your slide notes/caption:* "This represents the Error state. It's intentionally invisible to the user — the system silently falls back to a standard notification rather than showing an error message, to avoid confusing the user with a technical failure they can't act on."

---

## Slide 5 — Settings / Opt-Out

**Magic Design prompt to try:**
> "Minimal mobile app settings screen mockup, toggle switch, clean list layout"

**Header:** Daily BeReal Alert

**Visual:** A settings-row mockup with a toggle switch (Elements → search "toggle switch icon") — set it to the "on" position, soft green or blue

**Microcopy:**
> "On by default — one row inside BeReal's existing Notifications settings, nothing new to learn."

**Second microcopy (add as a second text box, representing the state *after* tapping the toggle off):**
> "You'll get the standard notification now."

**Button:** "Back" → **links to Slide 1**

---

## Linking It All Together (Canva steps)

1. On each slide, select the button/text element
2. Click the 🔗 **Link** icon in the top toolbar
3. Choose **Pages** → select the target slide number listed above
4. Repeat for every button on every slide
5. Click **Present → Preview** and click through the whole flow to test it end-to-end

---

## Optional: Apply the Transitions

- Add **Dissolve** or **Fade** between all 5 slides (Canva → click between slides → Transitions panel)
- Avoid anything flashy — BeReal's tone is calm, not energetic

## The 5–7 Sentence MAU Paragraph (for your submission)

Use or adapt this:

> This prototype addresses a narrow but high-leverage problem: users miss their daily BeReal simply because the notification blends into every other app alert. Rather than adding a new engagement mechanic, the design gives the existing notification a distinct sound and visual treatment so it's recognized before it's read, directly increasing the chance a user notices and acts on it. The Success screen reinforces this with a warm, personal confirmation rather than a generic system message, keeping the tone human rather than transactional. Deliberately, the feature includes no streaks, badges, or "come back tomorrow" banners — it doesn't try to manufacture a new reason to return, since that would work against BeReal's low-pressure identity. Instead, it protects an already-existing daily habit loop: today's notification gets acted on, and tomorrow's identical cue is now a recognized signal the user has already responded to successfully. This is retention infrastructure, not a growth gimmick — it increases MAUs by reducing accidental drop-off, not by adding pressure to engage.
