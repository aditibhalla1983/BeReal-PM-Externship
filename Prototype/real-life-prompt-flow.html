3. It shows lightlySmall tag, not a theme

If a prompt was used, it shows as a small tag on the post — friends see it as light context, not a filter or category the feed gets sorted by. No prompt used means no tag at all, same as today's post.

How it's storedData model

Same pattern as Daily Question — an optional field on the existing post record, not a new content type.

Prompt librarystatic list (rotates daily/weekly, no per-user targeting needed to start)
Prompt ID on postprompt_used: nullable (null if skipped — the common case, by design)
Verificationnone (no image matching against the prompt — it's a suggestion, never enforced)
Visibilitysame as the post itself

Fast to build, same as Daily Question — one nullable field and a chip UI in the camera screen. The only real design risk isn't technical, it's about staying optional.

Why this needs care: a themed prompt is the one idea on this list that touches the capture moment itself, not just what happens after. If prompts ever became expected, rotated too predictably, or started feeling like "today's theme," they'd start directing what people photograph — which is exactly what BeReal is built to avoid. Keeping "No prompt" as visually equal to the other chips, never pre-selected, and never nudged via notification is what keeps this a suggestion rather than a soft requirement.
